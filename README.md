# Humyn Daily AI Brief

Humyn Labs' daily and weekly brief on physical AI, robotics and voice AI, published with GitHub Pages.

- `index.html` is the reader page.
- `data/index.json` lists every issue, newest first.
- `data/daily/YYYY-MM-DD.json` holds one daily issue.
- `data/weekly/YYYY-MM-DD.json` holds one weekly roundup (keyed by the Monday of that week).

New issues are added by Humyn Labs' Daily AI Brief task. Team-only signals are not published here.
